# AI/ML Project Ideas by Skill Level

## Beginner
- Titanic survival prediction (classification, scikit-learn)
- House price prediction (regression)
- Simple sentiment analysis on movie reviews

## Intermediate
- CIFAR-10 image classifier with CNN
- Recommendation system (content-based, using cosine similarity on TF-IDF or embeddings)
- Basic RAG chatbot answering questions from a small document set

## Advanced
- Multi-agent LangGraph system with supervisor and specialized worker agents
- Corrective RAG (CRAG) pipeline with retrieval evaluation and query rewriting
- LLM gateway / rate limiter (infrastructure-focused, demonstrates systems thinking)
- Full-stack deployed AI application with Flask backend, live frontend, and public URL

## What Makes a Project "Portfolio-Ready"
1. It's deployed and publicly accessible
2. It has a clean, documented GitHub repo
3. It handles errors gracefully
4. It solves a real (even if small) problem
5. You can explain every design decision in an interview
