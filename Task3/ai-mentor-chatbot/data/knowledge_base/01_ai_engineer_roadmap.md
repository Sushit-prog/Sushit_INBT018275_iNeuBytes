# AI Engineer Learning Roadmap

## Phase 1: Foundations (Weeks 1-4)
Python fundamentals, NumPy, Pandas for data manipulation. Basic statistics and linear algebra concepts (vectors, matrices, gradients) are essential before touching ML libraries.

## Phase 2: Classical ML (Weeks 5-8)
Scikit-learn: regression, classification, clustering. Understand train/test splits, cross-validation, and evaluation metrics (accuracy, precision, recall, F1). Build 2-3 small projects on tabular data.

## Phase 3: Deep Learning (Weeks 9-14)
PyTorch or TensorFlow/Keras. CNNs for images, RNNs/LSTMs for sequences. Understand backpropagation conceptually, not just API calls. Build a CNN image classifier as a milestone project.

## Phase 4: NLP and LLMs (Weeks 15-20)
Tokenization, embeddings, transformer architecture basics. Hands-on with Hugging Face, LangChain/LangGraph. Learn prompt engineering and RAG (Retrieval-Augmented Generation).

## Phase 5: AI Engineering and Deployment (Weeks 21-26)
FastAPI/Flask backends for ML models. Docker basics. Deploying to Render/Railway. Building full-stack AI apps with a frontend, backend, and live API.

## Phase 6: Agentic Systems (Weeks 27+)
Multi-agent frameworks (LangGraph), tool use, memory systems, evaluation harnesses. This is where AI Engineer roles diverge from traditional ML roles - focus shifts to system design, not just model training.

## Key Principle
Depth beats breadth. One well-built, deployed project with a clean GitHub repo and README outperforms five half-finished notebooks in interviews.
